## 기능 명세

| # | 기능       | 동작                                                                 |
| - | ---------- | -------------------------------------------------------------------- |
| 1 | 입력창     | 할 일 텍스트를 입력. 빈 문자열·공백만 있을 경우 추가되지 않음.       |
| 2 | 추가 버튼  | 클릭 또는 `Enter` 키로 리스트에 새 항목 추가.                        |
| 3 | TodoList   | 추가된 할 일을 `<ul>`에 동적으로 렌더링.                             |
| 4 | 체크박스   | 클릭 시 완료 상태 토글. 완료된 항목은 취소선 + 흐려진 색으로 표시.   |
| 5 | 삭제 버튼  | 항목별 삭제 버튼 클릭 시 해당 todo 제거.                             |

## 구현 포인트

- **상태 관리**: `state.todos` 배열 하나로 모든 항목을 관리하고, 변경 후 `saveTodos()` → `render()` 순서로 호출하여 UI와 저장소를 일관되게 유지.
- **이벤트 위임**:`<ul>` 한 곳에만 `change`/`click` 리스너를 두고, `event.target.closest('.todo-item').dataset.id`로 항목을 식별. 항목마다 리스너를 다는 방식보다 메모리/성능 효율적.
- **localStorage 방어 코드**: `JSON.parse` 실패 시 빈 배열로 폴백하여, 저장소가 손상돼도 앱이 죽지 않도록 처리.
- **고유 ID 생성**: `crypto.randomUUID()` 기반. 미지원 환경을 위한 폴백도 함께 제공.
